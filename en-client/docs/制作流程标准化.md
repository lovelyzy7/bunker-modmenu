# 制作流程标准化

> 日常只需两个一键脚本；本文件是流程说明与手动方式备查。
> 参数与更多 FAQ 见 [`一键构建说明.md`](一键构建说明.md)。

## 0. 目录结构（en-client）

```
en-client/                    EN 客户端目录（JP 客户端见 ../jp-client/）
├─ modmenu/                 菜单工程源码（LGL 4.0 改造，含全部钩子与偏移；EN 专用 RVA）
├─ tools/                   构建 / 注入 / 本地化工具
│  ├─ toolpaths.example.json  工具路径模板（复制为 toolpaths.json 使用；留空=自动探测）
│  └─ targets.json            输入 APK 路径（原版 / 私服版）
├─ docs/                    文档（本文件 / 一键构建说明 / 操作指南 / 美化指南 / 制作记录）
├─ archive/                 归档（顶层保持与 jp-client 一致，不影响构建）
│  ├─ keys/                 签名密钥（nier.keystore；alias `nier`，密码 `nier123456`）
│  ├─ template/             原版与中文注释版模板 zip
│  ├─ scripts/              开发阶段调试脚本存档（正常构建不需要）
│  ├─ config/               运行配置示例
│  └─ releases/             成品 APK 说明
├─ resources/               输入 APK（不入库）
├─ dist/                    一键脚本成品输出（不入库）
└─ build/                   构建与解包缓存、日志（不入库）
```

## 1. 环境（一次性）

| 组件 | 要求 / 获取方式 |
|------|------------------|
| JDK 17 | 安装并加入 PATH；或在 `tools/toolpaths.json` 指定 `java_home` |
| Gradle | 无需单独安装：`modmenu/` 自带 Wrapper（首次运行自动下载 Gradle 8.7） |
| Android SDK + NDK | 设 `ANDROID_HOME` 指向 SDK（含 NDK 26.x）；或写进 `toolpaths.json` |
| apktool | 下载 `apktool.jar` 放到 `tools/apktool.jar`，或在 `toolpaths.json` 指定路径 |
| Python 3 | 运行一键脚本 |
| 输入 APK | 原版 3.7.1 与（可选）私服补丁版：放 `../resources/` 或改 `tools/targets.json` |

> 路径都可配置且支持自动探测；`tools/toolpaths.json` 是**本地文件（不入库）**，
> 模板见 `tools/toolpaths.example.json`。换机器一般只需复制模板并填路径。

## 2. 标准流程（推荐：一键脚本）

```bash
# 原版 + 菜单
build.bat                 # Windows（双击，自动识别私服补丁版 APK）
bash build.sh             # WSL / Git Bash

# 私服补丁版 + 菜单
build_patched.bat
bash build_patched.sh
```

脚本自动完成：编译菜单 → 提取 smali/so → 解包目标 APK（带缓存）→ 注入 → 打包 → 对齐 → 签名 → 输出到 `dist/`。
交互提问直接回车即推荐值；无人值守加 `--yes`。

### 手动方式（可选，等价于脚本内部步骤）
```bash
# 1) 编译菜单并解包提取
cd modmenu && ./gradlew assembleDebug
java -jar <apktool.jar> d app/build/outputs/apk/debug/app-debug.apk \
  -o ../build/menu_apktool -f

# 2) 注入 + 打包 + 签名
python3 tools/inject_modmenu.py --target original --yes
```

## 3. 游戏版本更新怎么办

1. 重新 dump 新版 `libil2cpp.so` + `global-metadata.dat`
2. 按方法名在 `dump.cs` 里找 `// RVA:`，对照 [`MOD制作记录.md`](MOD制作记录.md)【4. 偏移表】
3. 更新 `modmenu/app/src/main/jni/Main.cpp` 里的 offsets
4. 重新运行一键脚本

> 同版本的原版与私服补丁版共用同一套偏移（实测钩子点一致）。

## 4. FAQ

| 问题 | 处理 |
|------|------|
| 找不到输入 APK | 放到 `../resources/`，或修改 `tools/targets.json` |
| 找不到 apktool / build-tools | 配置 `tools/toolpaths.json`（模板见 example） |
| 安装失败（签名冲突） | 先卸载手机上的旧版本 |
| 换机器 | 复制 `tools/toolpaths.example.json` → `tools/toolpaths.json` 并填路径 |
| 二次构建太慢 | 保留 `build/work_<目标>/` 解包缓存，二次构建约 2~3 分钟 |
