# NieR Reincarnation · Lunar-Tear 内置 Mod 菜单 v1.0.1 操作指南

> 产物: `output/nier-mod-menu-v1.0.1.apk` (266.9 MB, 已签名)
> 密钥: `output/nier.keystore` (alias: `nier`, 密码: `nier123456`)
> 适用: 私服客户端 nierspww 3.7.1 (patched-local-6)

## 一、安装（重要）

1. **先卸载手机上的游戏**
   - 因为是重新签名，签名与旧客户端不同，直接覆盖安装会失败
   - 账号数据保存在私服服务器端，卸载不影响账号
2. 安装 APK（二选一）：
   - 把 `nier-mod-menu-v1.0.1.apk` 传到手机，点击安装
   - 或 USB: `adb install -r nier-mod-menu-v1.0.1.apk`
3. **授予悬浮窗权限**（首次启动会提示）：
   - Android 11+：设置 → 应用 → NieR Reincarnation → **显示在其他应用上层** → 允许
   - 没有此权限不会出现悬浮菜单

## 二、菜单功能与默认值

| 控件 | 功能 | 范围 / 默认 |
|------|------|-------------|
| 伤害倍率 | 我方对敌方伤害 × 倍率 | 滑块 1~333，默认 **333** |
| 防御倍率 | 我方受击伤害 ÷ 倍率 | 滑块 1~333，默认 **333** |
| 角色技能无CD | 3 个角色技能充能恒满，可连放 | 开关，默认 **开** |

> ⚠️ **讨伐战（BigHunt）内 `God模式免伤` / `防御倍率` 会自动停用**：
> 实测修改我方 HP 会导致波次结束时角色不播「消失动画」，从而卡死波次切换。
> 其他关卡（主线 / 活动 / 探索等）不受影响。

- 安装即生效（默认值），战斗中也可随时拖动滑块
- 菜单内的 **Settings → Save feature preferences** 勾选后可记住你的设置
- 伤害倍率内部已做 **15 亿**上限保护（与游戏伤害上限一致），正常使用不会因数值过大崩溃

## 三、注意事项

1. 只修改客户端战斗数值；私服服务端目前未发现有战斗结果校验
2. 游戏更新/换客户端后，钩子偏移（RVA）会失效，菜单会自动失效不生效（不会崩），
   需要按 `MOD制作记录.md` 重新 dump 并重做
3. 想还原原版：卸载本 APK，安装回原版客户端即可

## 四、故障排查

| 现象 | 处理 |
|------|------|
| 没有悬浮图标 | 检查悬浮窗权限；完全关闭游戏重开 |
| 打开菜单后闪退 | 记录 `adb logcat` 日志反馈 |
| 伤害没变化 | 确认滑块值 >1、处于战斗中；确认开关状态 |
| 安装失败 INSTALL_FAILED_UPDATE_INCOMPATIBLE | 先卸载旧版游戏 |
| 安装失败签名冲突 | 用 `adb uninstall com.square_enix.android_googleplay.nierspww` 后重装 |

## 服务器热切换（IP / 域名）

**用途**：不重新打包 APK，直接在游戏里切换连接的服务器（局域网 ↔ 公网）。

### 使用步骤
1. 展开菜单 → `服务器热切换` 分类
2. 点 `服务器地址(IP/域名:端口)` 输入，例如：

   | 输入 | 效果 |
   |---|---|
   | `192.168.2.6` | 只换 IP，端口保持默认（8003 / 8080） |
   | `example.com:80` | 域名 + 端口：API/CDN 都改到该端口（适配反向代理） |
   | `家里\|192.168.2.6` | 带备注（备注用 `\|` 分隔） |
3. `保存到地址簿`（可存多条，自动去重）
4. 用 `地址簿` 下拉选中，点 `应用选中地址`
5. **生效方式**：回标题重新登录（或重启游戏）——游戏已有连接不会自动断开
6. `应用输入框地址(临时)`：只临时生效，不写入地址簿
7. `失败自动切换`：连接失败 2 次自动换下一条（地址簿 ≥2 条时）
8. `记住上次选择`：重启游戏后自动应用上次的地址
9. `停止热切换`：关闭改写，恢复 APK 里烧进去的地址

### 说明
- 只改写 **8003（API）/ 8080（CDN）/ 80** 端口的连接目标，其它连接（443 等）不受影响
- 支持 **域名**：菜单自己解析（DNS），结果缓存 60 秒，失败自动重解析
- **引継ぎ/登录网页（auth/3000）也一起切**：菜单写 `/data/data/<包名>/files/auth_host.txt`（需打包时带
  `--auth-dynamic`，见 [`EN-auth动态化说明.md`](EN-auth动态化说明.md)）；不需要时删掉该文件即回退打包默认值
- 地址簿文件：`/data/data/<包名>/files/modmenu_servers.txt`，可直接编辑/备份
- 菜单顶部副标题实时显示当前生效的服务器

### 地址簿文件格式
```
enabled=1          # 热切换开关
current=2          # 当前选中条目（1 起）
fallback=1         # 失败自动切换
remember=1         # 记住上次选择
input=example.com  # 输入框最近内容
1=家里|192.168.2.6
2=公网|example.com:80
```

## 菜单里的「自检」两行（排障用）

菜单底部有：

```
自检基址: linker        ← libil2cpp 基址来源（linker 最好；maps-rx/maps-0 次之；maps-first 说明是旧回退）
自检挂钩: 6/6 上限ON     ← 6 个功能挂钩安装数 / 讨伐战上限补丁状态
```

- `6/6` = 全部功能已挂上；若出现 `4/6` 之类，说明有挂钩失败（会在 2 秒内被看门狗自动重装，重装成功会回到 `6/6`）
- 点「刷新自检」可立即刷新显示
- 如果长时间显示"等待游戏库…"：说明 libil2cpp 还没加载完（正常 1~2 秒内就会变）
