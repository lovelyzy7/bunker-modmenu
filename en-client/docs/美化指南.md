# Mod 菜单美化指南（LGL Mod Menu 4.0）

> 工程目录: `build/Android-Mod-Menu-4.0/`
> 任何改动完成后，都要走【制作流程标准化】的第 1、2 步重新构建与注入。
> 改 Java → 一定重编；改 C++ → 一定重编；只改文字也相同。

---

## 1. 标题 / 副标题 / 启动提示

文件: `app/src/main/jni/Menu/Setup.cpp` → `Init()`

| 元素 | 代码位置 | 说明 |
|------|----------|------|
| 大标题 | `setText(env, title, ...)` | 支持 HTML（`<b> <font color>`） |
| 副标题 | `setText(env, subtitle, ...)` | 支持 `<marquee>` 滚动 |
| 启动提示 | `Toast(env, ctx, ...)` | 可改文字/时长 |

示例：
```cpp
setText(env, title, OBFUSCATE("<b>NieR Reincarnation · Lunar-Tear</b>"));
setText(env, subtitle, OBFUSCATE("<b><marquee><p style=\"font-size:30\">"
                                 "<p style=\"color:green;\">Mod Menu v1.1</p> | "
                                 "伤害倍率 · 防御倍率 · 技能无CD</p></marquee></b>"));
Toast(env, ctx, OBFUSCATE("Mod Menu 已加载"), ToastLength::LENGTH_SHORT);
```

## 2. 悬浮图标

文件: `app/src/main/jni/Menu/Menu.cpp` → `Icon()`

1. 准备 PNG（建议 128×128，≤50KB）
2. 打开 https://www.base64encode.org → Encode files into Base64
3. 用生成的字符串替换 `Icon()` 里 `OBFUSCATE("...")` 的内容

动图（GIF）用 `IconWebViewData()`：
```cpp
// 网络 GIF（需要 android.permission.INTERNET）
return env->NewStringUTF(OBFUSCATE("https://i.imgur.com/xxxx.gif"));
// base64 GIF
return env->NewStringUTF("data:image/gif;base64,<编码>");
// 关闭 WebView 图标（用普通的 Icon）
return nullptr;
```

## 3. 颜色 / 尺寸（最常用）

文件: `app/src/main/java/com/android/support/Menu.java` 顶部 `// menu appearance` 区

| 字段 | 默认值 | 作用 |
|------|--------|------|
| `TEXT_COLOR` | `#82CAFD` | 功能名文字 |
| `TEXT_COLOR_2` | `#FFFFFF` | 控件文字 |
| `BTN_COLOR` | `#1C262D` | 按钮背景 |
| `MENU_BG_COLOR` | `#EE1C2A35` | 主面板背景（`#AARRGGBB`，前 2 位=透明度） |
| `MENU_FEATURE_BG_COLOR` | `#DD141C22` | 功能项背景 |
| `MENU_WIDTH` / `MENU_HEIGHT` | 290 / 210 | 面板尺寸（dp） |
| `POS_X` / `POS_Y` | 0 / 100 | 面板初始位置 |
| `MENU_CORNER` | 4f | 面板圆角 |
| `ICON_SIZE` | 45 | 悬浮图标大小 |
| `ICON_ALPHA` | 0.7f | 悬浮图标透明度 |
| `ToggleON` / `ToggleOFF` | GREEN / RED | 开关颜色 |
| `BtnON` / `BtnOFF` | #1b5e20 / #7f0000 | On/Off 按钮颜色 |
| `CategoryBG` | #2F3D4C | 分类标题背景 |
| `SeekBarColor` | #80CBC4 | 滑块轨道色 |
| `SeekBarProgressColor` | #80CBC4 | 滑块进度色 |
| `CheckBoxColor` / `RadioColor` | #80CBC4 / #FFFFFF | 复选框/单选框 |
| `CollapseColor` | #232F2C | 折叠标题背景 |
| `NumberTxtColor` | `#41c300` | 数值文字颜色 |

常用主题示例（暗金）：
```java
int TEXT_COLOR = Color.parseColor("#FFD54F");
int MENU_BG_COLOR = Color.parseColor("#F01A1A1A");
int ToggleON = Color.parseColor("#FFC107");
int SeekBarProgressColor = Color.parseColor("#FFC107");
String NumberTxtColor = "#FFC107";
```

## 4. 功能列表排版

文件: `app/src/main/jni/Main.cpp` → `GetFeatureList()`

| 语法 | 效果 |
|------|------|
| `Category_文字` | 分组标题（不计数） |
| `RichTextView_HTML` | 富文本说明（支持 b/i/u/font） |
| `RichWebView_HTML` | 完整 HTML/滚动/动画（不计数） |
| `ButtonLink_文字_URL` | 打开链接按钮（不计数） |
| `Collapse_标题` + `CollapseAdd_xxx` | 折叠分组 |
| `1_SeekBar_名字_1_333` | 滑块（编号=功能号） |
| `3_True_Toggle_名字` | 默认开启的开关 |

排版建议：首行放 `Category_战斗功能`，功能按重要度排列；说明文字用 RichTextView 折叠区。

## 5. 设置页（齿轮）

文件: `app/src/main/jni/Menu/Menu.cpp` → `SettingsList()`

- 已内置：保存偏好 (-1)、自动高度 (-3)、关闭设置 (-6)
- 自定义项用负数编号（如 `-8_Toggle_xxx`），在 `Main.cpp` 的 `Changes()` 里 `default:` 分支处理

## 外观主题（风格 A：仿 lunar-base / automata.css）

菜单已套用「NieR: Automata 地堡终端」配色（对齐 `lunar-base/web/static/css/automata.css`）：

| 角色 | 颜色 |
|---|---|
| 主面板底 | `#CFC7B0`（奶油）+ 2px `#1A1814` 边框 |
| 功能列表底 | `#D8D1BB` |
| 正文 | `#2C2922` |
| 分类条 / 数值强调 | `#1A1814` / `#6B0A0A` |
| 开关 ON / OFF | `#3A4D24` / `#6B0A0A` |
| 字体 | 等宽（MONOSPACE），近直角（圆角 2px） |

改法：编辑 `modmenu/app/src/main/java/com/android/support/Menu.java` **顶部**的颜色常量
（`TEXT_COLOR` / `MENU_BG_COLOR` / `BTN_COLOR` / `CategoryBG` / `BORDER_COLOR` …）；
按钮边框由 `rect(fill, stroke)` 生成。改完重新构建即可。
